# docs/guide/ — Guías (How-to)

**Propósito:** Instrucciones paso a paso para tareas operativas del proyecto.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `deployment.md` | **Guía completa** — Conexión y despliegue en Vercel (token, CLI, build, deploy, rollback, troubleshooting) |
| `docker.md` | Ejecución de la aplicación con Docker |
| `README.md` | Este archivo |

## Contenido

- **`deployment.md`** — **Guía exhaustiva** para conectar y desplegar en Vercel desde CLI: configuración de token (`VERCEL_TOKEN` vs `--token`), `vercel.json`, variables de entorno, flujo completo commit→push→deploy, verificación post-despliegue, rollback, y solución de problemas comunes con errores reales documentados.
- **`docker.md`** — Instrucciones para construir la imagen Docker, ejecutar contenedores, configuración de red y volúmenes, y comandos de docker-compose.

## Nota

Este directorio contiene solo guías activas. Las guías obsoletas o correspondientes a etapas anteriores del proyecto se encuentran en `docs/archive/`.
