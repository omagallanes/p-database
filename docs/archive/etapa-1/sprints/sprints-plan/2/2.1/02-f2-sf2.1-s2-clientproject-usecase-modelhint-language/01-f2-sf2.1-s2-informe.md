### 3.3 Detalles de Implementación

#### API Routes (patrón Platform)
- **GET**: Lista entidades ordenadas por nombre con count de prompts
- **POST**: Auth requerida, validación Zod, normalización (trim + uppercase), upsert por slug
- **Endpoint**: `/api/client-projects`, `/api/use-cases`, `/api/model-hints`

#### PromptForm State
```typescript
// Antes
useCase: string
clientOrProject: string
modelHint: string

// Después
clientProjectIds: string[]
useCaseIds: string[]
modelHintIds: string[]
```

#### UI Components
- **Client/Project**: Multi-select con badges + creación inline (Enter key)
- **Use Case**: Multi-select con badges + creación inline (Enter key)
- **Model Hint**: Multi-select con badges + creación inline (Enter key)
- **Language**: Select dropdown con 10 opciones (en, es, nl, fr, de, pt, it, catalan/valenciano, vasco, gallego), default "es"

#### Include N:M en Páginas
```typescript
include: {
  clientProjects: { include: { clientProject: true } },
  useCases: { include: { useCase: true } },
  modelHints: { include: { modelHint: true } },
}
```
