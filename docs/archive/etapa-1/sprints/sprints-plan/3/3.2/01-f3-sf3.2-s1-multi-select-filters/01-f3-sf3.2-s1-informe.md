## 12. Conocimiento técnico reutilizable

### Patrón 1: Multi-select con checkboxes y URL-driven state

**Descripción**: Patrón replicado de `toggleTag` para Platform y Category, usando `params.append()` y `params.getAll()` para manejar arrays en URL.

**Código de referencia** (`PromptFilters.tsx`):
```typescript
const togglePlatform = (platformId: string) => {
  const params = new URLSearchParams(searchParams.toString())
  const currentPlatformIds = params.getAll("platformIds")
  if (currentPlatformIds.includes(platformId)) {
    params.delete("platformIds")
    currentPlatformIds
      .filter((id) => id !== platformId)
      .forEach((id) => params.append("platformIds", id))
  } else {
    params.append("platformIds", platformId)
  }
  router.push(`/prompts?${params.toString()}`)
}
```

**Aplicabilidad**: Reutilizable para cualquier filtro multi-select URL-driven en el proyecto.

### Patrón 2: Lógica AND con `every` en Prisma para relaciones N:M

**Descripción**: Uso de `every` en lugar de `some` para filtrar prompts que cumplen TODAS las condiciones seleccionadas.

**Código de referencia** (`page.tsx`, `route.ts`):
```typescript
if (platformIds && platformIds.length > 0) {
  where.platforms = {
    every: {
      platformId: {
        in: platformIds,
      },
    },
  }
}
```

**Aplicabilidad**: Patrón estándar para filtros multi-selección con lógica AND en relaciones N:M.

### Patrón 3: Soporte dual para legacy y nuevo formato

**Descripción**: Implementar lógica condicional que soporta tanto el formato legacy (campo simple) como el nuevo formato (array con relación N:M).

**Código de referencia**:
```typescript
if (categoryIds && categoryIds.length > 0) {
  where.categories = {
    every: { categoryId: { in: categoryIds } }
  }
} else if (categoryId) {
  where.categories = {
    some: { categoryId: categoryId }
  }
}
```

**Aplicabilidad**: Útil durante transiciones de schema donde coexisten campos legacy y nuevas relaciones.

### Patrón 4: Parseo de arrays desde searchParams

**Descripción**: Función utilitaria para convertir searchParams que pueden ser string o string[] a array consistente.

**Código de referencia** (`page.tsx`):
```typescript
const platformIds = Array.isArray(searchParams.platformIds)
  ? searchParams.platformIds
  : searchParams.platformIds
  ? [searchParams.platformIds]
  : []
```

**Aplicabilidad**: Patrón estándar para manejar parámetros URL que pueden venir como valor único o array.
