# docs/developing/

**Directorio de trabajo activo para tareas en ejecución.**

Este directorio contiene documentación generada durante el desarrollo activo del proyecto. A diferencia de otros directorios en `docs/` que almacenan documentación consolidada y de referencia permanente, aquí se encuentra la documentación vinculada a tareas y fases en curso.

## Propósito

- Albergar documentos creados como parte de tareas de desarrollo en ejecución.
- Servir como espacio de trabajo para informes de estado, evaluaciones, análisis y cualquier otra documentación generada durante una fase activa.
- Proporcionar contexto inmediato a los agentes de desarrollo sin necesidad de buscar en el histórico del proyecto.

## Contenido actual

| Archivo | Descripción |
|---------|-------------|
| `evaluacion-documentacion-y-reglas.md` | Evaluación de la documentación del proyecto y reglas de comunicación. Creado durante la Fase 1 del Plan C. |

## Notas

- Los documentos aquí contenidos pueden moverse a `docs/guide/` o `docs/reference/` una vez que la tarea asociada esté completada y se considere documentación permanente.
- Este directorio no debe contener archivos de configuración, credenciales ni datos sensibles.
